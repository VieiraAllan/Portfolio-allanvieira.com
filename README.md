# Állan Vieira — Portfólio

Site estático do portfólio profissional de Állan Vieira, publicado em **https://allanvieira.com**.

## Contato

- Site: https://allanvieira.com
- Email: allan@allanvieira.com
- GitHub: https://github.com/VieiraAllan/

## Estrutura

- `index.html` — homepage principal.
- `cases/locker-rio.html` — estudo de caso Locker Rio.
- `cases/atipicos.html` — estudo de caso Atípicos.
- `cases/casa-mae-granola.html` — estudo de caso Casa da Mãe Granola.
- `assets/css/styles.css` — estilos globais.
- `assets/js/main.js` — interações, menu e animações.
- `assets/favicon.svg` — ícone do site.
- `robots.txt` e `sitemap.xml` — SEO.
- `netlify.toml` — configuração de publicação no Netlify (publica a raiz do repositório).

## Tecnologias

HTML, CSS e JavaScript puros, sem etapa de build. Para ver localmente, abra o `index.html` no navegador ou use qualquer servidor estático.

## Publicação

O site é publicado pelo Netlify a partir da branch `main` deste repositório.
